# 💜 BRUNA GAMER 💜
### O melhor site de fãs de Fortnite do Brasil

Site com a **loja de itens em tempo real**, missões do **Salve o Mundo**, guia de **Elementais**, **Skins, Emotes e Picaretas** e lista de favoritos.

![Fortnite](https://img.shields.io/badge/Fortnite-Battle%20Royale-9D00FF?style=for-the-badge)
![Status](https://img.shields.io/badge/Status-Online-FFD700?style=for-the-badge)

## 🔥 O QUE TEM NO SITE

- **Loja de Itens**: Atualiza todo dia às 21h BR direto da API oficial
- **Salve o Mundo**: Missões diárias, alertas de V-Bucks e heróis em destaque
- **Elementais**: Fogo, Água, Terra e Ar. Curta e comente seu favorito
- **Catálogo Completo**: Todas as Skins, Emotes e Picaretas do jogo
- **Favoritos**: Salve os itens que você mais quer ⭐ e acesse depois
- **Design**: Tema Fortnite - Fundo Preto + Roxo + Amarelo
